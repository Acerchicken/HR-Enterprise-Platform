| Mục | Nội dung |

## Lịch sử thay đổi

- dd/mm/yyyy: thay đổi gì, vì sao, link tới nơi quyết định.

## Nội dung quyết định

**Bối cảnh:** vấn đề cần quyết định, ràng buộc (quy mô, ngân sách, thời gian, NFR).

**Các giải pháp:**

| # | Giải pháp | Mô tả |
|---|---|---|
| A | | |
| B | | |
| C | | |

**Tiêu chí lựa chọn** (điểm 1–5, không trọng số):

| Tiêu chí | A | B | C |
|---|---|---|---|
| | | | |

**Giải pháp được chọn:** X, vì ...

**Trade-off:** điều chấp nhận mất đi và cách giảm thiểu.

**Tiêu chí nghiệm thu:** điều kiện đo được để biết quyết định đã được thực hiện đúng.

**Khi nào xem lại:** điều kiện khiến phải quyết định lại.
